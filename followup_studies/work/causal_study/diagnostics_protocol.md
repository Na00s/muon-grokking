# Five-seed numerical-gradient and next-update diagnostics

Written before running the new diagnostics. These are post hoc mechanistic interventions on the five previously captured first joint failures. Seed selection and event checkpoints are fixed by the preceding study.

1. At saved checkpoints at steps 6000, 10000, 14000 and the available 10-step event windows, compare stock float32 cross-entropy, accurate float32 cross-entropy, and an accurate float64 derivative on exactly the same frozen float32 logits. Measure lost target derivatives, violation of logit-shift invariance, relative derivative error, and downstream error separately for hidden weights, embeddings, and readout. The float64 derivative is cast to float32 before backpropagation through the shared float32 network. This controls loss arithmetic while retaining the same forward pass and network backward precision.
2. At the exact preceding step of each event, replay the original next update and require bitwise agreement of every model parameter, optimizer buffer, and RNG state with the captured collapse. Evaluate all eight choices of stock or accurate current gradients across the three optimizer groups. Existing model and optimizer states remain identical.
3. Ablate readout first-moment memory, current gradient, or all head state independently. Additional evaluation-only interventions apply the actual head update's common-class and class-centered components separately, and isolate its old-momentum and current-gradient numerator contributions under the original Adam denominator. The denominator-fixed components are counterfactual parameter updates, without a subsequent training step. Report this distinction explicitly.
4. Evaluate all eight pre/post parameter-group hybrids. This independently attributes the exact acute step to hidden weights, embeddings, and readout.

All arms use only existing training labels and states. Held-out examples are evaluation only. Compare accuracy, loss, parameter update norms, and Adam numerator components. No result will be called a complete upstream causal mechanism solely because a terminal intervention changes accuracy. In particular, failure of an accurate final step to repair an event can reflect accumulated history; a successful long matched branch is the appropriate test of numerical dependence.

Tests will check the accurate derivative against autograd in double precision, its shift-invariance property, preservation of tiny target derivatives, the Adam component reconstruction, exact replay, and independence of checkpoint state between arms. Additional continuation arms, if needed, will be declared separately before execution.
